## Why this repository exists

The `git-panel` shot used to open a project inside the Jx monorepo, so `git status` reported whatever the person running the pipeline happened to have uncommitted. The picture changed on every machine.

This repository is materialised at capture time from a recipe with pinned author and committer dates, so its history and its dirty set are the same everywhere — one modified file, one new file, one deletion, forever. ::
:::
