# Extending

Jx is built to be extended. First-party extensions (the Markdown parser, the data connector, auth) use only the public extension hooks — anything they can do, your extension can do.

This section covers:

- **Extensions** — packages that contribute formats, classes, project sections, capability methods, server mounts, and connectors to a Jx project.
- **Embedding** — Studio is backend-agnostic: implement the platform adapter and backend protocol to host it anywhere.
- **Contributing** — working in the Jx monorepo and on these docs.

Pages in this section are being written; the [extensions spec](https://github.com/jxsuite/jx/blob/main/specs/extensions.md) is the authoritative reference meanwhile.
