10A Component
What it looks like

Fifteen lines.
Reactive. Encapsulated. Done.

DOM-native property names. Reactive bindings inline. Functions as data. The whole component is one self-contained, version-controllable file.

→ AND YOU'LL NEVER HAVE TO WRITE IT BY HAND.

{ "$id": "Counter", "state": { "count": 0, "increment": { "$prototype": "Function", "body": "state.count++" } }, "tagName": "my-counter", "children": [ { "tagName": "span", "textContent": "${state.count}" }, { "tagName": "button", "textContent": "+", "onclick": { "$ref": "#/state/increment" } } ] }

11The Content Layer
