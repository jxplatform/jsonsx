# Keyboard Shortcuts

Studio is designed for keyboard-driven workflows. Here's every shortcut, organized by category.

## Editing

| Shortcut       | Action                                     |
| -------------- | ------------------------------------------ |
| `Ctrl+Z`       | Undo last edit                             |
| `Ctrl+Y`       | Redo last undone edit                      |
| `Ctrl+S`       | Save current file                          |
| `Delete`       | Delete selected element                    |
| `Ctrl+D`       | Duplicate selected element                 |
| `Ctrl+C`       | Copy selected element                      |
| `Ctrl+V`       | Paste element (as child)                   |
| `Ctrl+Shift+V` | Paste as sibling                           |
| `Enter`        | Start inline editing (on text elements)    |
| `Escape`       | Exit inline editing / deselect             |
| `Ctrl+Shift+F` | Quick search (files, components, commands) |

## Canvas Navigation

| Shortcut          | Action                   |
| ----------------- | ------------------------ |
| Middle-click drag | Pan canvas               |
| Space + drag      | Pan canvas (alternative) |
| `Ctrl+scroll`     | Zoom canvas in/out       |
| `Ctrl+0`          | Reset zoom to 100%       |
| `Ctrl+Shift+F`    | Fit canvas to viewport   |
| Click element     | Select element on canvas |

## Panel & Navigation

| Shortcut         | Action                           |
| ---------------- | -------------------------------- |
| `Ctrl+B`         | Toggle left panel (activity bar) |
| `Ctrl+J`         | Toggle right panel (inspector)   |
| `Ctrl+L`         | Toggle AI Assistant chat panel   |
| `Ctrl+W`         | Close current tab                |
| `Ctrl+Tab`       | Switch to next tab               |
| `Ctrl+Shift+Tab` | Switch to previous tab           |
| `Ctrl+Shift+E`   | Focus files explorer             |

## Source Control (Git)

| Shortcut       | Action                                  |
| -------------- | --------------------------------------- |
| `Ctrl+Shift+G` | Open source control panel               |
| `Ctrl+Enter`   | Commit (when commit message is focused) |
| `Ctrl+Shift+P` | Push to remote                          |

## AI Assistant

| Shortcut      | Action                       |
| ------------- | ---------------------------- |
| `Ctrl+L`      | Open AI Assistant panel      |
| `Enter`       | Send message (in chat input) |
| `Shift+Enter` | New line (in chat input)     |
| `Escape`      | Stop AI streaming response   |
